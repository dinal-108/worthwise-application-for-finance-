# 🌸 WorthWise – AI for Finance
WorthWise is a pastel, mobile-friendly web app that teaches young people money skills through AI, games and cartoon stories. Built for Arthaton 2026 (AI for Finance).

## What it does
- 🧠 AI Money Assistant, 🛡️ Scam & Fraud Detector (plus a Scam Detective game)
- 💰 Smart Budget, 🧬 SpendDNA, 🔁 Subscription Detective
- 📈 SIP Time Machine and Inflation Simulator
- 🧾 Tax Helper (old vs new regime, FY 2026-27)
- 🎬 FinFlix interactive cartoon stories, 🎵 Money Rhymes
- 🎯 Financial IQ quiz, Needs vs Wants, Myth Buster, Money Story
- English by default, one-tap Hindi mode, light/dark mode, text-size setting

## How to run
Download `index.html` and open it in any browser. No installation needed (internet is needed once to load the Chart.js library).

## AI models and APIs used
- The submitted demo uses a rule-based demo model and dummy data. No external AI API is called and no real money is involved.
- Planned real AI: a small backend can call the Anthropic Claude API while keeping the API key on the server. This is not enabled in the demo.
- Library: Chart.js (charts).

## Important
Educational demo only. Not financial, tax or investment advice. Returns shown are illustrative assumptions.
